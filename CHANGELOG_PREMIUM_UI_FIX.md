# NEURAL GOLD — Premium UI & Stability Fix

## Fixed

- Fixed `TypeError: can't compare offset-naive and offset-aware datetimes` by normalizing stored subscription expiry timestamps to UTC before comparison.
- Fixed duplicate Telegram callback-query acknowledgements that could trigger `Temporary service error` alerts on button taps.
- Simplified the main dashboard button labels for Telegram mobile readability.
- Kept the requested bottom navigation: `← BACK` on the left and `⌂ MENU` on the right.
- Improved the welcome screen copy so the bot explains its purpose instead of relying on Telegram's empty-chat placeholder.
- Kept premium modules button-driven: Price, Signal, Analysis, Account, Access & Plans, Settings, Support.
- Added a timezone regression test.

## Important

The Telegram `No messages here yet...` text is a Telegram client placeholder shown before the bot has sent a message. It is not generated by `main.py`. After `/start`, the bot sends the NEURAL GOLD dashboard.
